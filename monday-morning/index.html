Background before Notebook One

When a neuron “fires,” it sends a fast electrical pulse.

The cell’s voltage is usually quiet. Input pushes it upward. If it crosses a threshold, the neuron sends a spike and then resets.

RestingThe neuron is ready, but not sending a spike.
ThresholdThe “enough input” line.
SpikeA brief pulse, also called an action potential.

Spikes are one way neurons turn input into messages.

Spike timeWhen did the pulse happen?
Spike countHow many pulses happened during the input?
Firing rateHow often is the neuron spiking?
PatternAre spikes steady, bursty, or irregular?
In Colab, we will read the model by counting spikes and comparing the voltage plot.

Simplify carefully

Our model keeps the firing logic, not every biological detail.

Voltage changes over time Input pushes voltage up Leak pulls voltage back Threshold triggers reset

Real neurons use ion channels and chemistry. Our code keeps the part we can test today.

Read code like a map

You only need the few lines that match the idea.

SettingsResting voltage, threshold, input strength.
LoopUpdate the voltage one tiny time step at a time.
If statementIf voltage reaches threshold, record a spike and reset.
for each time step:
    leak = -(voltage - rest)
    push = R * input[t]
    voltage += (leak + push) * dt / tau

    if voltage >= threshold:
        record spike time
        reset and pause

What happens when the model waits to be more sure?

Low boundFaster choices, but more chances to be wrong.
High boundSlower choices, but more evidence collected.
Strong driftClear evidence usually reaches the right bound faster.
More noisePaths wobble more, so outcomes vary more.

Be careful

What did we include? What did we leave out? What changed? What should we test next?
