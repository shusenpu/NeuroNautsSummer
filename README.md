# NeuroNauts Summer School Materials

Static materials for the NeuroNauts Summer School computational neuroscience activities and the eight-week neuron biophysics study guide.

- `8-week-study-materials/` opens the full minibook, PDF, figures, exercises, quizzes, code, datasets, rubrics, and teacher notes.
- `monday-morning/` opens the full Brain Code morning session.
- `first-15/` redirects to the full morning session so older links still work.
