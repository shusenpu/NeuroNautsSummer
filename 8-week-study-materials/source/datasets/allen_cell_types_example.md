# Allen Cell Types Example Route

This file is a mentor note, not a required student assignment.

## Purpose

Use one Allen Cell Types example as an authentic companion to the simplified figures. The goal is not to download a large dataset. The goal is to show that real neurons have morphology, electrophysiology traces, and model descriptions that can be compared carefully.

## Suggested Mentor Workflow

1. Open the Allen Cell Types Database in a browser.
2. Choose one excitatory/pyramidal-looking cell with a visible morphology reconstruction and electrophysiology traces.
3. Ask the student to identify soma, dendritic tree, and likely axon path if visible.
4. Show one current-clamp trace and ask: Where are the spikes? Are the spike heights mostly similar? Does the firing rate change with stimulus?
5. End with a limitation sentence: "This real cell is more complex than our teaching model, so the model explains one mechanism rather than every feature."

## Student-Safe Claim Template

"The Allen example shows that real neurons have complex shapes and real spike traces. Our model is simpler, but it helps explain how voltage, threshold, and spike timing can be measured."
