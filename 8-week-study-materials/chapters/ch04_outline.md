# Chapter 4 Outline: Action Potentials, Refractory Periods, Myelin, and Propagation

## 1. Opening Question

- Question: How does a small graded signal become a fast all-or-none spike that travels down an axon?
- Target answer: once threshold is crossed, voltage-gated Na+ and K+ channel timing creates a stereotyped action potential and resets the membrane.
- Current source: `minibook_v2/source/chapters/action_potentials_and_propagation.md`.

## 2. Why This Matters

- This chapter explains the event that most students call a “neural signal.”
- It separates spike shape from message strength.
- Propagation and myelin prepare the student for spike trains and timing.

## 3. Visual First

- Required visual: `fig_08_action_potential_phases.svg`.
- Companion visuals: `ap_phase_strip.svg`, `myelin.svg`, `gating_timeline.svg`.

## 4. Core Concepts And Terms To Define

- Subsection headings: Threshold crossing; Depolarization; Overshoot; Repolarization; After-hyperpolarization; Refractory period; Propagation and myelin.
- Exact terms to define: action potential, spike, voltage-gated channel, depolarization, overshoot, repolarization, after-hyperpolarization, refractory period, myelin, node of Ranvier, propagation.
- Keep channel timing qualitative, not equation-heavy.

## 5. Read The Graph

- Graph to read: `action_potential_phase_plot.svg`.
- Student reads: time in ms on x-axis, V_m in mV on y-axis, threshold line, peak, refractory interval.
- Skill: identify phase durations and threshold crossings.

## 6. Worked Example And Try One Yourself

- Worked example: Given a voltage trace, identify when threshold is crossed and estimate spike duration from threshold crossing to return near rest.
- Expected solution: read times from graph; subtract start time from end time; include ms.
- Try one: If threshold crossing is at 2 ms and return near rest is at 5 ms, spike duration is 3 ms.

## 8. Assessment And Teacher Note

- 5-question quiz:
  1. Define action potential.
  2. Label threshold and peak on a trace.
  3. Explain why stronger input does not make one taller spike.
  4. Estimate spike duration from two time points.
  5. Explain how myelin changes propagation.
- Teacher note: likely misconceptions are that a spike is any voltage bump, that stronger stimuli make taller action potentials, and that the spike physically jumps through empty space instead of being regenerated along excitable membrane.
