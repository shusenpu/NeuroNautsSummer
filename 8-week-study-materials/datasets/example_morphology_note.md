# Example Morphology: NeuroMorpho.Org

## Source Name

NeuroMorpho.Org  
Main site: <https://neuromorpho.org/>  
FAQ: <https://neuromorpho.org/myfaq.jsp>  
Standardized SWC format note: <https://neuromorpho.org/StdSwc1.21.jsp>

## Why No Data File Is Bundled Here

This folder does not include NeuroMorpho.Org reconstruction files. The mentor should download any morphology file directly from NeuroMorpho.Org and follow the current terms of use, citation requirements, and source-publication credit requirements.

NeuroMorpho.Org is a curated inventory of digital neuron and glia reconstructions. Its FAQ explains that each reconstruction has a NeuroMorpho.Org ID and associated metadata, and that digital reconstructions can support scientific education, morphology analysis, and computational modeling.

## Educational Purpose

Use one downloaded morphology to help the student see that "neuron shape" can become data. A morphology file is not just a picture. It is a list of connected points that describe branches, lengths, and locations.

This example is useful for:

- comparing dendritic branching between neuron types,
- showing that morphology can be measured,
- explaining why a real neuron is more complex than a classroom cartoon,
- preparing for later modeling ideas without requiring calculus.

## How To Obtain One Example Manually

1. Open <https://neuromorpho.org/>.
2. Use the search tools to find a beginner-friendly neuron, such as a pyramidal neuron or a Purkinje cell.
3. Open the detail page for one reconstruction and record its NeuroMorpho.Org ID.
4. Read the metadata: species, brain region, neuron type, archive, and original publication.
5. If download is permitted under the current terms, download the standardized SWC file.
6. Keep the downloaded SWC file in a local working folder outside this repository unless the mentor decides it is appropriate to include it with full attribution.

## Suggested Student Prompt

After opening one morphology page, answer:

1. What neuron type is this?
2. What brain region is it from?
3. Does it look more like a simple cartoon or a branching tree?
4. What measurement could you make from the shape?

If a morphology image or rendering is used in the minibook, credit NeuroMorpho.Org, the NeuroMorpho.Org ID, the original archive or publication listed in the metadata, the page URL, and the access date. Label the figure as a real reconstruction or rendering, not a schematic cartoon.
