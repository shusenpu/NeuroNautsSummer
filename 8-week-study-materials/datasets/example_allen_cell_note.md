# Example Real Cell: Allen Cell Types Database

Allen Brain Atlas: Cell Types Database  
Main site: <https://celltypes.brain-map.org/>  
Example electrophysiology page: <https://celltypes.brain-map.org/experiment/electrophysiology/474626527>  
Example morphology page: <https://celltypes.brain-map.org/experiment/morphology/474626527>  
Terms of use: <https://alleninstitute.org/legal/terms-of-use>

## Why No Data File Is Bundled Here

This folder does not include Allen data files. The student and mentor should download any real data directly from the Allen site and follow the current Allen Institute terms, citation policy, and classroom-use expectations.

The Allen Cell Types overview describes the database as containing electrophysiological, morphological, transcriptomic, and model data from individual cells. It also notes that electrophysiology recordings, morphology images, 3D reconstructions, and model parameters can be downloaded from cell-specific pages.

## Educational Purpose

Use one Allen cell to show that the cartoon neuron in Chapter 1 is a simplified map, not the full biological reality. A real cell page lets the student see:

- a real morphology image or reconstruction,
- real electrophysiology traces,
- cell metadata such as species, cortical area, layer, and dendrite type,
- the connection between a cell's shape and its voltage response.

## How To Obtain One Example Manually

1. Open the Allen Cell Types Database at <https://celltypes.brain-map.org/>.
2. Choose **Cell Feature Search**.
3. Filter for a cell with both **Electrophysiology** and **Morphology** available.
4. For a concrete starting point, open specimen `474626527` using the links above.
5. On the electrophysiology page, view one long-square current injection response.
6. On the morphology page, view the cell shape.
7. If you download files, save them outside this repository unless the mentor has checked the current terms and citation requirements.

## Chapter Connection

- Chapter 1: compare real morphology with the simplified neuron map.
- Chapter 4: connect current injection to action potentials.
- Chapter 6: use the same cell as a bridge to model language, such as fitted GLIF or biophysical models.
- Chapter 8: ask the student to make a claim such as "this real cell's shape and firing response show why one cartoon cannot represent every neuron."

## Suggested Student Prompt

Look at the real morphology first. Then look at one voltage trace. Write three sentences:

1. What part of the cell looks like an input region?
2. What evidence shows the cell can fire spikes?
3. What does this real example add that the cartoon did not show?
