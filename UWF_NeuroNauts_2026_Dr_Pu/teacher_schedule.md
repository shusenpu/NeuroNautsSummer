# Brain Code One-Day 6-Hour Teacher Schedule

This schedule is for the `UWF_NeuroNauts_2026_Dr_Pu` HTML slide deck. The tutorial is intentionally beginner-friendly: no calculus, no advanced biophysical models, and no research-project depth.

## Core Student Rhythm

Use this rhythm for every notebook or graph activity:

1. Predict
2. Run
3. Look
4. Explain

Required final student product:

> I changed ___. The graph showed ___. I think this means ___. One limitation is ___.

## If Running Late

- Compress slides 8-9 into one verbal timeline if the Nobel map runs long.
- Skip slides 20-26 if students already have enough everyday-brain examples.
- Compress slides 43-45 into one verbal pause before the decision model.
- Skip slide 58 if Notebook One timing is tight; input strength and threshold are enough.
- Use either slide 69 or 70, not both, if Notebook Four spike-train practice runs long.
- Skip slides 77-78 if Notebook Six needs more setup time.
- Keep slides 85-92. The Notebook Six final sentence frame is the main student product.

## Slide Notes QA

Every slide has `data-notes` written in the same three-part pattern:

- teaching cue
- likely misconception
- transition sentence

Use those notes as a pacing guide rather than as a script.

## Colab Activity Map

Notebook Zero:

- Activity 1: Run one cell
- Activity 2: Edit one sentence
- Activity 3: Change one signal value
- Activity 4: Explain one plot

Notebook One:

- Morning simple neuron first run
- Basic input-strength practice

Notebook Two:

- Morning simple decision first look
- One path, one bound, one tiny evidence-push change

Notebook Three:

- More comprehensive afternoon graph experiment lab: baseline, fair comparisons, summaries, and mini-share evidence.
- Activity 5: Change input strength
- Activity 6: Change threshold
- Activity 7: Change input duration

Notebook Four:

- New spike-train lab, not based on Notebook Three
- Activity 8: Count spikes
- Activity 9: Estimate firing rate
- Activity 10: Same count, different timing
- Activity 11: Compute simple ISI gaps
- Activity 12: Choose spike-train evidence

Notebook Five:

- Short decision restart and bridge after spike trains
- One path and several paths

Notebook Six:

- Comprehensive afternoon decision lab, not based on Notebook Two
- Activity 13: Rerun the same settings
- Activity 14: Change decision bound
- Activity 15: Change noise
- Activity 16: Match plot to question
- Activity 17: Choose final evidence, audit one limitation, and prepare the mini-share

## Final Share Block

Slides 81-89 are a Notebook Six working block:

- Slides 81-84: audit the model and name what the chosen graph can and cannot show.
- Slide 85: copy the final sentence frame into Notebook Six.
- Slides 86-87: choose the final graph and write four short sentences.
- Slide 88: partner-check the graph explanation in Notebook Six.
- Slide 89: present from Notebook Six.

Slide 91 is a bridge to the deeper course. Use it to say, “Today we stayed with simple models; the longer course zooms into ions, channels, action potentials, and spike timing.” Do not teach those mechanisms in the one-day tutorial.
